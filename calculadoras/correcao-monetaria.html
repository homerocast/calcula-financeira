O que é correção monetária

Correção monetária é a atualização de um valor ao longo do tempo por um índice de preços, para compensar a perda de poder de compra causada pela inflação. É usada em contratos de aluguel, dívidas, indenizações judiciais e comparações de valores entre épocas diferentes.

Qual índice usar

IPCA é o índice oficial de inflação do Brasil (usado pelo Banco Central como meta) — a escolha padrão para a maioria das correções. INPC é parecido, mas focado em famílias de renda mais baixa, e é o índice usado para reajustar o salário mínimo. IGP-M é historicamente o mais usado em contratos de aluguel, embora tenha maior volatilidade por incluir preços no atacado.

Como o cálculo é feito

A calculadora busca a variação mensal do índice escolhido, mês a mês, entre a data inicial e a data final, direto na API do Banco Central. Depois, multiplica essas variações entre si (juros compostos) para chegar ao fator de correção acumulado, que é aplicado sobre o valor original.
